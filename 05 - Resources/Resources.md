# Resources

Cross-project reference material: templates, knowledge bases, voice and brand guides, and Jobs.

**Jobs** are the piece that turns this vault from a memory into an operating system. A Job is one master note per recurring task that hands a future session the complete skill for that task — the procedure, the quality bar, and links to exactly the notes that job needs and nothing else. Read one note, have the whole job.

No Jobs are built yet, by choice. The trigger for building one is simple: the second time I catch myself explaining the same task from scratch, that task earns a Job note here (or in `02 - TSA/Jobs/` if it only belongs to the agency).
