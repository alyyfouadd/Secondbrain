# jaredrhod-marketing

jaredrhod's marketing playbook, by Jared Rhodenizer (@jaredrhod), CC BY-SA 4.0. Upstream: github.com/jaredrhod/ai-marketing-skills

**This skill holds no content of its own.** The playbooks live in the vault at `05 - Resources/Marketing/`, which is the single source of truth. This file is a pointer, so editing a note there changes what this skill teaches and there is nothing to keep in sync.

## The one rule

Never produce marketing output cold. Read the principles plus the matching playbook first, every single time. The context is the whole point.

## What to read, in this order

Read only what the task actually needs.

1. **Always first:** `05 - Resources/Marketing/jareds-takes.md` — the 35 core principles everything else sits on.
2. **If the task touches the funnel or overall strategy:** `05 - Resources/Marketing/the-fundamentals.md` — Content, Lead Magnet, Tripwire, Core Offer, Profit Maximizer.
3. **Then the one playbook that matches the task**, all in `05 - Resources/Marketing/`:
   - Copy, headlines, hooks, sales and opt-in pages: `marketing-copywriting.md`
   - Long-form sales letters, the 12-step structure: `marketing-sales-letter.md`
   - Email, sequences, broadcasts, subject lines: `marketing-email.md`
   - Paid ads on any platform: `marketing-fb-ads.md`
   - Lead magnets and opt-in offers: `marketing-lead-magnets.md`
   - Organic content, posts, videos, content calendars: `marketing-content.md`
   - Metrics and deciding off a number: `marketing-analytics.md`

`05 - Resources/Marketing/Marketing.md` is the folder index and carries the same map with descriptions.

## Applying it here

The playbooks come from a direct-to-consumer information business. TSA sells high-value services to businesses. The principles carry unchanged; the funnel mechanics (tripwire pricing, low-ticket lead magnets) need translating to a B2B service sale rather than being applied literally. Say so when it matters instead of forcing the shape.

For client work, read the client's own note as well — `02 - TSA/Clients/Alex Foods/Alex Foods.md` for Alex Foods — so the output is primed on the actual business, not just the method.
