# el-ghaly-screens

**Folder index for `02 - TSA/el-ghaly-screens/`.** *(Named after the folder rather than `README.md`, which is the convention for an asset folder here. The reason is mechanical: `structure.py` recognises asset folders from a hardcoded list and this one is not on it, so a bare `README.md` is reported as a note folder with no index. **Registering the folder in that list is the tidier fix and it is a source-code change** — queued in [[Active Priorities]].)*

**The only direct evidence TSA has about El Ghaly Motorcycle.** Four screenshots of their Facebook page, captured by Aly on his iPad on 21 September 2026 at 12:41 PM Cairo.

**They exist because this machine cannot reach Facebook.** The session proxy returns 403 on every Facebook host, verified 21 September. **Without these, every statement about the prospect's current output is somebody's description of it** — which is exactly the failure `TSA Client System` §4d was paid for on client one.

| File | What it shows |
|---|---|
| `01-page-profile.jpg` | The page header: name, follower count, bio with the dealer roster, category, location, review score, and the cover image |
| `02-post-weekly-competition.jpg` | Post, 1 day old. **The weekly photo competition they are already running**, with a 1,000 EGP accessory prize |
| `03-post-student-offer-video.jpg` | Post, 2 days old. **A talking-head video in the shop, 171 likes and 109 comments** — the highest-engagement item seen |
| `04-post-refund-10k.jpg` | Post, 29 August. *"We returned 10,000 EGP to our customer"* — a trust story, and the post above it at 51 likes / 16 comments |

**Downscaled to 1000px and saved as JPEG on purpose.** The originals were 21 MB across four files. Aly syncs this repo to an iPad over mobile data, and screenshots only have to be legible. **Never commit full-resolution captures here.**

**These are a snapshot of one day.** They are evidence of what was true on 21 September, not a live feed. Everything read off them is written up in `El Ghaly Motors Pitch` §1 and §2.
